# CCTV Monitoring Dashboard

A secure and scalable CCTV Monitoring Dashboard built to provide real-time surveillance management, live camera monitoring, and role-based access control for organizations requiring centralized security operations.

## Overview

The CCTV Monitoring Dashboard enables administrators and authorized users to monitor live camera feeds, manage surveillance devices, and access monitoring features through a secure web-based interface. The platform is designed for high availability, performance, and scalability.

## Key Features

### Real-Time Monitoring

* Live CCTV camera streaming using RTSP integration
* Low-latency video playback
* Multi-camera viewing support
* Real-time surveillance monitoring

### Role-Based Access Control (RBAC)

* Multiple user roles with granular permissions

## Architecture

The application follows a modern client-server architecture:

1. React.js frontend for monitoring and management.
2. Express.js backend for API handling and business logic.
3. MongoDB for storing users, permissions, and device information.
4. RTSP integration for live camera streaming.
5. AWS-hosted deployment with production-grade server configuration.
